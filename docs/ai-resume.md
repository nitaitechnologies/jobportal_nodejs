# AI Resume Builder & Job Tailoring (092–093)

ChatGPT-powered draft generation for candidates. Content is **always labelled as AI-generated** so both product and users know the source.

## Feature flag

| Env | Purpose |
|-----|---------|
| `OPENAI_API_KEY` | Required. When empty, AI routes return **404** and `/me` → `features.aiResumeEnabled=false` |
| `OPENAI_MODEL` | Default `gpt-4o-mini` |
| `ENABLE_AI_RESUME` | Optional override (`true`/`false`). Defaults to on when a key is set |
| `AI_RESUME_RATE_LIMIT_*` | Per-IP generation limits |

Never commit real API keys. Put them only in local `.env` / host secrets.

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| `POST` | `/api/v1/candidate/profile/resume/ai/build` | Build resume draft from profile (092) |
| `POST` | `/api/v1/candidate/profile/resume/ai/tailor` | Tailor draft for a job `jobId` (093) |

Auth: candidate JWT. Rate-limited separately from login.

### Build body

```json
{ "tone": "professional", "focusRoles": ["Sales Executive"] }
```

### Tailor body

```json
{ "jobId": "<24-char ObjectId>", "tone": "professional" }
```

## Response (always includes AI labels)

```json
{
  "success": true,
  "message": "AI resume draft generated — review carefully before using",
  "data": {
    "aiGenerated": true,
    "aiLabel": "AI-generated",
    "aiDisclaimer": "This content was generated by AI (ChatGPT). Review and edit before using...",
    "provider": "openai",
    "model": "gpt-4o-mini",
    "generatedAt": "2026-09-22T10:00:00.000Z",
    "purpose": "resume_builder",
    "job": null,
    "resume": {
      "headline": "...",
      "summary": "...",
      "skills": [],
      "experience": [],
      "education": [],
      "certifications": [],
      "plainText": "..."
    },
    "tips": ["..."],
    "uiHint": {
      "showAiBadge": true,
      "badgeText": "AI-generated",
      "bannerText": "AI-generated resume draft — review carefully before using"
    }
  }
}
```

Clients **must** show `uiHint.badgeText` / banner (or equivalent) whenever `aiGenerated` is true. Do not present drafts as human-written.
